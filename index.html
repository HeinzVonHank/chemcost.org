Exact labels

Every ChemCost label is computed exactly from frozen supplier quotes: $136.91 per gram of product for the reaction above. An agent gets credit only when its own number lands within 10% or 25% of it.

The task

From a reaction description to a dollar figure per gram.

An agent reads a reaction as a chemist wrote it down and returns one number: what it costs to buy the material for the run at a 1 mmol scale, per gram of product. Supplier prices are never in the prompt and cannot be recalled reliably, so the answer has to come from the tools. Because the label is computed from a frozen supplier snapshot under a fixed rule, every prediction is scored exactly.

01

Ground the names

Map each name to one structure. Abbreviations collide: TEA can mean triethylamine or triethanolamine.

Typical failureGives up when a name does not resolve and returns nothing.
02

Retrieve quotes

Pull every pack-level quote for each chemical: supplier, pack size, price, reported purity.

Typical failureGuesses a price from memory, then lands 2× off.
03

Select packs

Work out the mass each component needs, then buy whole packs of qualifying purity that cover it.

Typical failureReads 0.23 g as 230 g, an error of three orders of magnitude.
04

Aggregate

Sum the packs bought, leave out solvents, and divide by the grams of product the run yields.

Typical failureDrops the palladium catalyst and comes in 3.6× under.
Ground-truth label
c = Σi ∉ solvent qiMP · 10−3 · y/100

qi is the price of the whole packs bought to cover component i's required mass mi = ei Mi · 10−3 g. A pack is charged in full even when only part of it is used, so this is a procurement cost, not a consumption cost.

Metric · cost tolerance accuracy
CTA@k = 1N Σj 𝟙 [ |ĉj − cj| / cj ≤ k% ]

The share of reactions priced within k% of the label. Refusals, unparsable answers and exhausted step budgets stay in the denominator. We report CTA@10 and CTA@25.

Results

Tool access is necessary, and still not enough.

Twelve models run as ReAct agents with the same four tools and a 40-step budget. The best reach about half the reactions within 25%, below the human reference. Noise in how the reaction is written, especially free-text or OCR-style formatting, pulls every model down further.

Findings

Where procurement reasoning breaks.

Every trajectory is logged, so a wrong number can be traced to the stage that produced it.

Tool use

Failed runs make more calls, not fewer.

Across models, average tool calls track CTA@25 closely (r = 0.98), mostly because weak models barely enter the workflow. Within strong models, failures come with extra calls, concentrated in supplier-quote retrieval that never converges. GPT-5 fails the other way, stopping early.

Tool calls in failed trajectories relative to successful ones.

Input noise

Formatting is what makes agents give up.

Rewriting a reaction as prose or OCR-damaged text raises abstention by 26.3 points on average. No other single kind of noise adds more than 6. The causes differ by model: exhausted step budgets, unfinished work, or outright refusal.

Reaction structure

Each synthesis step costs accuracy.

Route depth is the strongest difficulty axis. Every model loses roughly 24 to 25 points of CTA@25 going from single-step to deep routes, while the number of components in a single step matters much less.

CTA@25 by number of synthesis steps, pooled across agents (paper setting).

Domain models

Knowing the chemicals is not the same as pricing them.

Chemistry-tuned models name the right components with high precision and still score zero, because they rarely call the tools and estimate prices from memory instead.

Data & code

Run it on your own agent.

The release includes the evaluation harness, every record with its label and selected packs, and the frozen pricing database the labels come from. One script recomputes every label from that database.

# install and fetch data
git clone https://github.com/HeinzVonHank/ChemCost.git
cd ChemCost
pip install -e ".[eval,tests]"
python scripts/download_data.py
python scripts/verify_labels.py

# evaluate a ReAct agent
python scripts/run_evaluation.py \
  --agent react --provider anthropic \
  --model claude-sonnet-4-6 \
  --output results/react.json
